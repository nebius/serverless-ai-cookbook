# Evo2 NIM (hosted, bounded)

Use `bionemo_evo2` only with nonclinical public or synthetic DNA containing
ACGTN. Generation is capped at 512 tokens. Prefer a fixed seed when comparing
runs. Explain that generated sequence is a model hypothesis requiring expert
biosafety review and validation. Return FASTA and JSON artifact links.
